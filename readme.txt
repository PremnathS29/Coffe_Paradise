COFFE PARADISE PROJECT README

Welcome to the Coffe Paradise website repository! This is a responsive, multi-page front-end web project designed for a premium coffee brand rooted in Tamil Nadu, India. The website features a luxurious aesthetic, highlighting the brand's unique coffee blends, gallery, and story.

FEATURES

Multi-Page Architecture: Includes dedicated pages for Home, About, Gallery, Menu, and Contact.

Fully Responsive Design: A mobile-friendly layout featuring a hamburger menu for seamless navigation on smaller screens.

Dynamic Navigation: Active page highlighting so users always know where they are on the site.

Interactive UI Elements: Hover effects on menu items, interactive buttons, and pop-up alerts for ordering and contact forms.

Custom Brand Styling: A warm, coffee-inspired color palette (#ddad75, #502010, #ff8800) that perfectly matches the Coffe Paradise aesthetic.

FILE STRUCTURE

TECHNOLOGIES USED

HTML5: Semantic structure and content layout.

CSS3: Flexbox, Grid, custom styling, and media queries for responsiveness.

Vanilla JavaScript: DOM manipulation, form handling, and mobile menu toggling.

FontAwesome (CDN): For social media icons on the About page.

RECENT UPDATES & FIXES

This version of the codebase includes several core improvements for performance and standard compliance:

JavaScript Error Prevention: The contact form event listener is now conditionally loaded, preventing silent null reference errors on pages that do not contain the form.

Navigation Context: Added "active" classes to the HTML navigation links to dynamically highlight the user's current page based on the existing CSS.

HTML5 Standard Compliance: Removed invalid "px" units from inline image width and height attributes across all HTML files.

HOW TO RUN

Clone or download this repository to your local machine.

Ensure your Images folder is in the same directory as your HTML files and matches the structure listed above.

Double-click index.html to open it in your default web browser. No server setup is required!
